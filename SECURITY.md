# Security Policy

## Supported Versions

Only the latest release gets fixes.

## Reporting a Problem

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/garrettbuilds/wp-comments-off/security/advisories/new),
not in a public issue. Include the WordPress and PHP versions, the host if it matters, and the
steps to reproduce. Expect a first reply within a week.

A way a bot can still post a comment, trackback or pingback with the plugin installed counts as a
security problem.
